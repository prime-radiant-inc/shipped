No releases this week — but two brand-new repositories that both point outward. A community **code of conduct** signals that these projects expect outside contributors, and **agentic-usage-meter**, a macOS menu-bar app for tracking coding-agent subscription quotas, went public. Underneath the new repos, serf logged another heavy direct-push week and a research campaign in superpowers-autoresearch closed out with a measured, substantial cost cut.

## Featured

<article class="repo">

### [prime-radiant-inc/code-of-conduct](https://github.com/prime-radiant-inc/code-of-conduct)

<p class="repo-desc">The Prime Radiant Community Code of Conduct.</p>

<RepoStat org="prime-radiant-inc" name="code-of-conduct" week="2026-07-27" />

A small repo with an outsized signal: the Contributor Covenant (v3) adapted into a Prime Radiant community code of conduct, refined after review feedback. You don't publish a code of conduct for a codebase only you touch — you publish it when you expect people to show up. With outside contributors already turning up in the commit logs, the timing tracks.

</article>

<article class="repo">

### [prime-radiant-inc/agentic-usage-meter](https://github.com/prime-radiant-inc/agentic-usage-meter)

<p class="repo-desc">A macOS menu-bar meter for coding-agent subscription quotas.</p>

<RepoStat org="prime-radiant-inc" name="agentic-usage-meter" week="2026-07-27" />

Multi-provider quota tracking stood up in a single week: OpenCode account qualification and profile-lifecycle handling, SuperGrok credential refresh without reconnecting, and sample-data marking in account settings. It also arrived with real public-release infrastructure — signed Sparkle auto-update releases with fail-closed automation, confirmation-based updates, privacy-safe product screenshots, and public documentation. Built to be shipped, not just demoed.

</article>

### [prime-radiant-inc/serf](https://github.com/prime-radiant-inc/serf)

<p class="repo-desc">A non-interactive coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="serf" week="2026-07-27" />

A second consecutive four-figure-commit week, nearly all direct push. The dominant visible thread was the web UI's compact input footer — designed, constrained, documented, then implemented with simplified session-footer facts. Around it: mobile viewport and shell-chrome pinning, job-notification descriptions surfaced in notifications, task-mutation summaries showing task titles, and a refinement of how shell tool-calls are presented.
