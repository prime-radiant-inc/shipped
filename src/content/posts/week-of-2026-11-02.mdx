### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-11-02" />

Six tagged patch releases, each a bare version tag with GitHub's auto-generated changelog. The run finishes last week's two-track internal refactor and turns to steady bug-fixing: a local "Hey Evener" wake-word detector with a trial harness, arming the realtime voice model directly instead of through a classifier layer, and quieting a duplicate watchdog-silence report; a web UI with a deliberate visual identity replacing the old beige palette, unfoldable "Thinking" traces open by default, and a batch of structural UX repairs; hub/session plumbing keeping sidebar project order stable, bounding every resume wait by its own budget, and projecting pending mutation authorship into the right namespace; and stabilization work across several load-sensitive CI lanes. Sole author: **Jesse Vincent (staff, `obra`)**.

</article>

### [prime-radiant-inc/shepherd-pr](https://github.com/prime-radiant-inc/shepherd-pr)

<p class="repo-desc">A portable coding-agent plugin for shepherding GitHub pull requests through CI and review.</p>

<RepoStat org="prime-radiant-inc" name="shepherd-pr" week="2026-11-02" />

Two tagged releases, both with hand-written notes. **v0.4.0**: `pr-settle.py` now discovers a repository's own merge gates — its base branch, that branch's required status checks and approving reviews, merge-queue rules, and whether the repo runs RoboRev — before a push, printed up front with a new `--gates` flag; a single `--until auto|settled|approved|merged` flag replaces separate modes, covering CI-only, approval-gated, and merge-queue repos, with `auto` as the default and every final line carrying a `next=` status. **v0.4.1**: that new default `auto` wait now correctly reports a still-needed human approval instead of waiting on it. Sole author: **Jesse Vincent (staff, `obra`)**.

</article>
