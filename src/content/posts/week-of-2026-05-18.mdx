The last of the backfill's pre-launch weeks — the week immediately before this blog's live coverage picks up. Two releases lead: **episodic-memory** cut a `v1.4.2` of cross-platform install fixes, and **slackline** shipped default-recipient and lint-cleanup releases. Behind them, a broad week: a `serf` TUI visual redesign, a full Codex OAuth provider in `sprout`, a third macOS VM backend in `stockyard`, and recall-subsystem hardening in `lace`. Two outside contributors landed fixes on episodic-memory.

## Featured

<article class="repo">

### [obra/episodic-memory](https://github.com/obra/episodic-memory)

<p class="repo-desc">A memory and recall layer for coding-agent sessions.</p>

<RepoStat org="obra" name="episodic-memory" week="2026-05-18" />

`v1.4.2` was a cross-platform install pass: a postinstall script fixed for non-macOS/Linux, a single-instance lock for `sync --background`, and per-required-package manifest probing before launching the MCP server — plus a retryable-error sentinel written on summarizer failure, closing a silent-failure gap. Jesse Vincent drove the release; two outside contributors landed fixes the same week — **Andy Wright** (GitHub login `minyek`, the same account credited the prior week) fixed a summarizer-cwd / resume-fallback bug, and **K. Z.** (`monsterxz9`) fixed the Codex summarizer ignoring a deprecated model from history.

</article>

<article class="repo">

### [prime-radiant-inc/slackline](https://github.com/prime-radiant-inc/slackline)

<p class="repo-desc">A Slack-identity CLI for AI agents.</p>

<RepoStat org="prime-radiant-inc" name="slackline" week="2026-05-18" />

Releases `v0.2.1` and `v0.2.2`: a default-recipient fix so thread replies to bot-authored messages now emit by default, plus a lint-cleanup pass that named several previously-magic wire-format error codes and Slack scopes as exported constants. Sole contributor: Jesse Vincent.

### [prime-radiant-inc/sprout](https://github.com/prime-radiant-inc/sprout)

<p class="repo-desc">An experimental self-improving multi-agent coding system.</p>

<RepoStat org="prime-radiant-inc" name="sprout" week="2026-05-18" />

An OpenAI/Codex OAuth provider, end-to-end: credential-lifecycle management, refresh-race hardening, and macOS-keychain-direct secret writes (kept out of argv), with a Codex adapter handling streamed tool calls. Active-subagent status was surfaced in both terminal and web UIs and scoped correctly per session, fixing several status-leak-across-sessions bugs. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [prime-radiant-inc/stockyard](https://github.com/prime-radiant-inc/stockyard)

<p class="repo-desc">A coding-agent VM orchestrator.</p>

<RepoStat org="prime-radiant-inc" name="stockyard" week="2026-05-18" />

Added Apple's `container` tool as a third macOS VM backend alongside Firecracker and the outgoing vfkit path: a full `AppleContainerBackend` (start / stop / delete / list, a log-follower, a PTY-backed exec session), plus fixes for real-world container-CLI JSON quirks and multi-arch image builds caught by an actual arm64 build. Sole contributor: Matt Windbrook.

</article>

<article class="repo">

### [obra/lace](https://github.com/obra/lace)

<p class="repo-desc">A lightweight agentic coding environment.</p>

<RepoStat org="obra" name="lace" week="2026-05-18" />

Security and reliability hardening on the `recall` subsystem: file modes (`0o600`/`0o700`) applied to the SQLite index and transcript files, a SQLite `busy_timeout` so contending writers wait instead of erroring, FTS5 query-error wrapping, persona-name validation (rejecting leading dashes, whitespace, and control characters), and a `search order: recent` option. Sole contributor: Jesse Vincent.

</article>
