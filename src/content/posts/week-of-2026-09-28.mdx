### [obra/superpowers-chrome](https://github.com/obra/superpowers-chrome)

<p class="repo-desc">Claude Code plugin for direct Chrome browser control via DevTools Protocol — zero dependencies.</p>

<RepoStat org="obra" name="superpowers-chrome" week="2026-09-28" />

Tagged release v3.0.8. A real security fix: the existing `data-sen-secret` DOM-marker guard only caught credential-shaped content when a caller read back full serialized HTML, so `eval`, `extract`, and `attr` calls that returned plain text or a bare attribute value could still leak a marked secret's value verbatim — reported by a downstream user, confirmed reproducible on v3.0.6, and fixed by checking the live DOM for the marker before any of those code paths run. A follow-up fix corrected how dialog text renders when an action triggers a native browser dialog mid-flight, which had been showing "unknown" and "???" placeholders instead of the dialog's actual text and accept/dismiss instructions. Both merged PRs and the release: **Ada Sen (staff)**. Two PRs opened but not merged this window remain open as of the snapshot: Ada Sen's own follow-up scrubbing password/one-time-code fields from capture, and an outside contributor's (`sophieow`) addition of a `CHROME_WS_HEADLESS` environment variable.

</article>
