**Simon Willison**'s `external-sandbox` family ships its next round of hardening: **`prime-radiant-inc/external-sandbox-container`** tags **0.2.0**, **`prime-radiant-inc/external-sandbox-v86`** tags **0.4.0**, and **`prime-radiant-inc/external-sandbox-quicksand`** tags **0.2.0**, all three adding a flag to start the managed proxy with every destination denied by default; the container and Quicksand backends also add upstream TLS verification against the system trust store this round. **`prime-radiant-inc/evener`** tags no release this week — a sharp contrast with the prior week's burst of seven patch releases — but keeps shipping quota-wait reliability work, reasoning-replay fixes, and a large test-suite cleanup. This week is still open: the data below runs cutoff-to-cutoff through Friday evening, not the full calendar week.

<article class="repo">

### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-11-16" />

By far the busiest repo this window, as in every prior week, but with no tagged release. A reliability cluster around "quota wait" bookkeeping continues: reconciling waits by timestamp across a read cut, keeping quota-wait stamps monotonic across restores, dropping a legacy unstamped fallback, and rendering the pending half of a quota wait on the pane and row. Session/transcript handling gets a parallel push: replaying tool-call argument bytes losslessly across restore, settling Responses-API calls and reasoning parts consistently, pricing only the reasoning the Responses wire actually sends, and converging the live reasoning preview with reassembled details by item identity — aimed at keeping cross-provider LLM fallback coherent. A security fix confines the sandbox's restricted Seatbelt outbound network access to explicitly granted roots. The week's largest single thread is test-suite cleanup: a long run of commits drops duplicate and tautological tests across the agent and hub layers, removes dead skips and compile-only test wrappers, and replaces fixed timeouts with budget-aware waits. In-org author: **Jesse Vincent (staff, `obra`)**, plus outside contributions from **Asish** (`NopeCharon`) and a first-time outside contributor, **Huyvux12**.

</article>

### [prime-radiant-inc/agent-session-archiver](https://github.com/prime-radiant-inc/agent-session-archiver)

<p class="repo-desc">Archive original agent session traces across hosts over SSH, independently of viewers.</p>

<RepoStat org="prime-radiant-inc" name="agent-session-archiver" week="2026-11-16" />

This repo predates the window, but this is effectively its coming-out: it goes from essentially untouched to a working tool. A first real implementation lands SSH-based archiving of agent session traces across hosts (#1), followed by a deployment script that installs one version everywhere (#2). A bug where legitimately-superseded transcript versions were being refused instead of kept gets fixed and hardened, including a recovery-scoping test and a check that rejects superseded name collisions (#3). Further hardening streams captures over SSH instead of staging them for rsync, confines received batches to trace members, reports a refused source cleanup alongside the pull's own error, and rejects batch entries that shadow recovery markers as directories. Sole author: **Jesse Vincent (staff, `obra`)**.
