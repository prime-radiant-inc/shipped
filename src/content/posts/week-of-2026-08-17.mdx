Two unrelated renames collided this week, so it's worth naming them up front so they don't get tangled in the reading: **`prime-radiant-inc/serf` is now `prime-radiant-inc/evener`** — a full GitHub repo rename, same non-interactive coding agent covered in past posts as "serf," wearing its new name from here on. Separately, **the `ledger` tool is becoming `chit`** at the packaging and binary layer — the GitHub repo is still named `ledger`, but the Homebrew formula, release assets, and command surface all now say `chit`. Around those two, **automatic-sshfs** went public — built in large part by the (recently renamed) evener agent working alongside its owner — and **winpepper** cut an outside-contributed alpha. This week is still open: the data below runs through midday Friday, not the full calendar week.

### [prime-radiant-inc/automatic-sshfs](https://github.com/prime-radiant-inc/automatic-sshfs)

<p class="repo-desc">Automatically mount remote filesystems over SSH on macOS via FUSE-T and ControlMaster.</p>

<RepoStat org="prime-radiant-inc" name="automatic-sshfs" week="2026-08-17" />

Built start-to-finish in about a day: SSH-config enumeration with `Include`-directive support, a pure reconcile diff of desired vs. actual mount sets, control-path resolution, FUSE-T mount/unmount wiring, a `launchd` install/uninstall path with `WatchPaths`, and a CLI `list` command — capped with a review-findings cleanup pass (cycle guard, prereq check, control-path detection, naming). A meaningful share of the docs and fix commits are authored under the `evener` identity rather than a human name — the `evener` coding-agent tool (see below) committing autonomously while helping build this repo, not an outside contributor.
