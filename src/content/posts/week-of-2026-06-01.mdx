A launch-heavy week. **obol** — a cost estimator that reads an agent transcript and tells you what it cost, with bindings for Python, Go, and TypeScript — appeared and shipped a `v0.1.1` with a full multi-channel release pipeline behind it. **homedir-manager** split out of the dotfiles repo into a standalone deploy-and-audit engine. And a run of releases landed across `slackline`, `clearance`, and `clipfan`, the last of which grew a self-healing SSH mesh.

<section class="summary">

<WeekSummary week="2026-06-01" />

<p class="caveat"><em>Two numbers to read carefully this week. The active-repo count is inflated by an org-wide housekeeping commit — a single "project-map" doc added to dozens of otherwise-quiet repos — so many of those repos saw no feature work. And the tagged-release count is dominated by clipfan, which tags a release per merged change (29 patch tags this week alone); that's a packaging cadence, not 29 distinct milestones. The real feature work is in the repos called out below.</em></p>

## Featured

<article class="repo">

### [obra/homedir-manager](https://github.com/obra/homedir-manager)

<p class="repo-desc">A symlink-deploy and audit tool for dotfiles content repos, plus a macOS defaults helper (POSIX sh and Swift).</p>

<RepoStat org="obra" name="homedir-manager" week="2026-06-01" />

New this week — the "management machinery" carved out of `obra/dotfiles` into its own standalone engine: multi-repo discovery, deploy and audit engines, and a marker-based content-repo registry. It added a `merge-children` manifest directive that expands a directory's children into a symlink target, with drift-checking and orphan detection, and shipped Shellcheck-clean CI across Linux/macOS/Swift plus a pre-push secret-audit hook.

</article>

<article class="repo">

### [prime-radiant-inc/obol](https://github.com/prime-radiant-inc/obol)

<p class="repo-desc">Reads an AI-agent transcript and estimates what it cost — a Rust core with C-ABI bindings for Python, Go, and TypeScript.</p>

<RepoStat org="prime-radiant-inc" name="obol" week="2026-06-01" />

New this week, and it launched with distribution already solved: alongside the `v0.1.1` release came a full multi-channel publish pipeline built in the same window — PyPI (four platform wheels via OIDC), crates.io (OIDC trusted publishing), and npm (`@primeradianthq/obol`). Naming a cost estimator "obol" — the coin you pay the ferryman — is the kind of detail that tells you who built it.

</article>

<article class="repo">

### [prime-radiant-inc/obol-go](https://github.com/prime-radiant-inc/obol-go)

<p class="repo-desc">The generated Go binding for obol — loads the native library at runtime via <code>purego</code>, no cgo.</p>

<RepoStat org="prime-radiant-inc" name="obol-go" week="2026-06-01" />

New this week: the bootstrap of obol's Go binding target, tag-generated automatically from `prime-radiant-inc/obol`'s releases. Its commits are machine-generated release artifacts, so this repo is really the automation half of obol's launch rather than a separate project.

</article>

<article class="repo">

### [prime-radiant-inc/clearance](https://github.com/prime-radiant-inc/clearance)

<p class="repo-desc">The Clearance product workspace — a Markdown viewer monorepo, currently a native Swift/macOS app.</p>

<RepoStat org="prime-radiant-inc" name="clearance" week="2026-06-01" />

Two tagged releases (`v1.3.5` and `v1.3.4`). A local CLI install option landed, macOS download instructions got clearer, and a native-appearance polish pass fixed dark-appearance handling, preserved transparent icon corners, added a standard zoom shortcut, and opened bundled release notes read-only. External contributor **Jonah** (`alibi85`) is credited on one commit, and a macOS open-app fix (`#51`) came in via a Codex-authored branch.

</article>

<article class="repo">

### [prime-radiant-inc/slackline](https://github.com/prime-radiant-inc/slackline)

<p class="repo-desc">A single-binary Go CLI that gives AI agents a Slack identity.</p>

<RepoStat org="prime-radiant-inc" name="slackline" week="2026-06-01" />

A busy release week (`v0.3.3`, `v0.3.2`, `v0.3.0`, `v0.2.3`, plus a commit-only `v0.3.1`), all aimed at cutting jq friction: a `listen --type` allowlist filter, `reaction_added`/`removed` unified into one `reaction` event with an action field, and a distinct timeout exit code for `ask`. The Slack skill set consolidated too — `slackline-provision-bot` folded into `using-slack`, the plugin made self-distributing — and a `read --thread` tail-omission bug got fixed.

</article>

<article class="repo">

### [prime-radiant-inc/clipfan](https://github.com/prime-radiant-inc/clipfan)

<p class="repo-desc">A clipboard-sync daemon for a Mac plus a remote tmux fleet.</p>

<RepoStat org="prime-radiant-inc" name="clipfan" week="2026-06-01" />

The release count here is a packaging artifact (a tag per merged change), but the week's real headline is a self-healing SSH mesh: `mesh-heal` brought decentralized roster discovery, host-key trust hardening (closing a TOCTOU and a truncation gap), resilient sync-pin host prep, and Go-daemon restart recovery. Fleet UX picked up an About window, an explicit Add-Peer success state, and SSH-aware outbound indicators, alongside reliability fixes to launchd `PATH`/`tmux` resolution and stale-session handling.

</article>
