Three repos shipped tagged releases this week: **`obra/blogosphere`** cuts v0.1.0, its first release ever, behind a from-scratch signed-and-notarized macOS build pipeline; **`obra/superpowers`** ships v6.4.2; and **`obra/superpowers-chrome`** ships v3.0.6. Underneath them, **`prime-radiant-inc/evener`** has its busiest week by commit count, and picks up a handful of commits from an outside contributor doing macOS code-signing CI work. This week is still open: the data below runs through Friday evening, not the full calendar week.

## Featured

<article class="repo">

### [obra/blogosphere](https://github.com/obra/blogosphere)

<p class="repo-desc">Local-first, multi-platform blogging client for an 11ty blog that lives in a GitHub repo — the repo is the database.</p>

<RepoStat org="obra" name="blogosphere" week="2026-09-21" />

Its first tagged release, v0.1.0, behind a from-scratch signed-and-notarized macOS release workflow: a Developer ID identity imported and matched against the configured signing identity, a `.dmg` build that gets stapled and verified, pinned actions with no saved token, and the release gated to run only on tagged commits on `main` after checks pass. Alongside the release infrastructure: a nightly-fuzz timeout fix for async property tests that were outlasting the default limit, and a string of UI polish items — an activity-popover arrow that now points at the sync button's center, syntax colors fixed to a readable accent-independent blue, draft/publish toolbar copy, and markdown line alignment fixes. Sole author: **Jesse Vincent (staff)**.

</article>

<article class="repo">

### [obra/superpowers](https://github.com/obra/superpowers)

<p class="repo-desc">An agentic skills framework & software development methodology that works.</p>

<RepoStat org="obra" name="superpowers" week="2026-09-21" />

Tagged release v6.4.2, "leaner plans from writing-plans" — a rewrite of the `writing-plans` skill's core philosophy: a plan is decisions, not a transcript, built around a step recipe, a proportion check, and an assumption that the reader is capable. Still mostly invisible to the commit-count column above — its work lands on a `dev` branch, not `main`, which is the only branch this blog's tooling walks for commits; the merged-PR count is the reliable signal here. By merged PR: sole author **Jesse Vincent (staff)**.

</article>
