The widest week of the eight, and for two different reasons. Part of it is a genuine surge: obol, agentic-usage-meter, and superpowers-chrome all cut releases, awesome-superpowers opened, and serf logged its third consecutive four-figure-commit week. The other part is a single deliberate event — on August 6, an org-wide sweep added a service-catalog entry (`catalog-info.yaml` + `ABOUT.md`) to nearly every repo at once, one "docs(map)" commit each. That's why the active-repo count jumps. We count both honestly below, and we're careful not to let the sweep stand in for per-repo product work.

## Featured

<article class="repo">

### [prime-radiant-inc/agentic-usage-meter](https://github.com/prime-radiant-inc/agentic-usage-meter)

<p class="repo-desc">A macOS menu-bar meter for coding-agent subscription quotas.</p>

<RepoStat org="prime-radiant-inc" name="agentic-usage-meter" week="2026-08-03" />

A week of rapid iteration — six tagged releases, `v0.1.1` through `v0.2.4` — and the throughline is concurrency hardening, not a single feature. Every persisted-state write was serialized through one mutation queue, reconnect-refresh blocking was reference-counted, in-flight refreshes are now drained before a reconnect touches shared state, and account-removal and cancellation races got closed out. Along the way it also picked up multi-org accounts, a provider-request link, and Node 24 release artifacts. This is what fixing account-management race conditions under fast release cadence looks like.

</article>

<article class="repo">

### [obra/superpowers-chrome](https://github.com/obra/superpowers-chrome)

<p class="repo-desc">A Claude Code plugin for direct Chrome control via the DevTools Protocol — zero dependencies.</p>

<RepoStat org="obra" name="superpowers-chrome" week="2026-08-03" />

Three releases in a week, each with a distinct character. `v3.0.3` honors stringified-JSON payloads for structured actions (Postel's law), contributed from an outside branch with added behavioral test coverage. `v3.0.4` was a dedicated security release, resolving every open Dependabot alert. `v3.0.5` is reliability and hardening across the MCP and CLI launch paths: passing image-tool and port-lookup args directly instead of through a shell, reporting *why* Chrome failed to launch, keeping Chrome's sandbox on except where it genuinely can't work, surfacing spawn failures instead of crashing the server, and isolating test profile and cache paths from the user's real cache dir.

</article>

A task-list panel redesign in the web UI — rows grouped by status, latest updates inline, a progress header, timezone-safe timestamps — and a substantial piece of work on recoverable, retained tool output for the agent: bounded retained-output readers, paging and search over that output, artifacts scoped to session trees, and a hardened artifact-lifecycle cleanup.

<article class="repo">

### [obra/superpowers](https://github.com/obra/superpowers)

<p class="repo-desc">An agentic skills framework and software-development methodology that works.</p>

<RepoStat org="obra" name="superpowers" week="2026-08-03" />

Zero direct commits, all of it landing through squash-merged PRs — and the throughline is real: Hermes Agent harness support (eval-verified bootstrap) plus a run of SDD reliability fixes. Event-driven bounded waits drove wait-timeouts down to effectively none, small same-shape tasks now batch into one dispatch, "rule and continue" ledgers a ruling for non-catastrophic conflicts instead of blocking with a question, and a guard keeps dispatched subagents from dispatching further subagents. Devin CLI support landed too, along with multi-agent guidance corrected against the Codex source and docs-navigation improvements.
