The story this week is two tools that didn't exist on Monday and shipped by Sunday: **blogosphere**, a local-first blogging client built from an empty repo to mobile builds in seven days, and **smevals**, a small-model eval framework Simon Willison stood up from scratch and released twice off the same week's work. Around them, **teststrip** and **obol** cut releases, and commits landed from a noticeably wider circle of contributors across both orgs.

## Featured

<article class="repo">

### [obra/blogosphere](https://github.com/obra/blogosphere)

<p class="repo-desc">A local-first, multi-platform blogging client for an 11ty blog that lives in a GitHub repo — the repo is the database.</p>

<RepoStat org="obra" name="blogosphere" week="2026-07-13" />

New this week — and not a soft launch. The corrected commit log shows a full application built from zero: a Tauri v2 + Vite + React scaffold under TS-strict and Biome, a from-scratch sync engine (serialized pushes, a stale-head guard, an activity log, partial-validation pushes, discard-changes), a rewritten document-style editor surface, image fetch-on-miss resolution, and Android and iOS mobile builds. A late "delight pass" layered on publish-URL previews, ⌘K, a deploy watch, resume, versions, and live view. An adversarial review swept a batch of confirmed findings before ship — rename collisions, push/pull races, quit-flush, SSRF hardening. The public-launch essentials — MIT license, README, a boot-failure screen, platform-honest connect copy — are real too; they're the last layer on top of a much bigger build.

</article>

<article class="repo">

### [prime-radiant-inc/smevals](https://github.com/prime-radiant-inc/smevals)

<p class="repo-desc">A framework for running evals against small (and large) models.</p>

<RepoStat org="prime-radiant-inc" name="smevals" week="2026-07-13" />

Also new this week: Simon Willison built smevals from scratch and cut two releases off that same-week work. It's a full CLI-plus-reporting tool, not a cleanup pass — initial run and grade commands, a Checklist→Grader rename, an HTML report app with multiple graders and clickable tags, a terminal Markdown report command, multi-grader support, and example evals (haiku, Pelican, markdown-tables). A README-generating docs command, Python 3.10+ support, and the `SMEVAL_*`→`SMEVALS_*` environment rename round it out.

</article>

<article class="repo">

### [prime-radiant-inc/teststrip](https://github.com/prime-radiant-inc/teststrip)

<p class="repo-desc">A macOS photo-culling app — catalog-first, non-destructive, AI-assisted. Early development; not ready for use.</p>

<RepoStat org="prime-radiant-inc" name="teststrip" week="2026-07-13" />

Cut `v0.2.0` on the back of a culling-workflow redesign: a dedicated culling-workstation shell, simplified verdict copy ("Keep" / "Toss" instead of percentages), reads-card signal ordering, and burst-rail thumbnail and caption polish. It also persisted a burst-stack capture-interval preference, added a run tracker with a full completion summary, fixed Library-grid activation to open the Library loupe rather than the culling loupe, and repositioned and muted the RAW+JPEG badge.

</article>

<article class="repo">

### [prime-radiant-inc/obol](https://github.com/prime-radiant-inc/obol)

<p class="repo-desc">Read an AI-agent transcript and estimate what it cost — a Rust core with C-ABI bindings for Python, Go, and TypeScript (Bun + Node).</p>

<RepoStat org="prime-radiant-inc" name="obol" week="2026-07-13" />

Cut `v0.8.0`, driven by a pricing-data refresh: the bundled snapshot now includes the `gpt-5.6` model family, alongside CI and lint repairs (cargo-fmt drift, and a version test whose expectation is now derived from the workspace manifest rather than hard-coded).

</article>

### [prime-radiant-inc/serf](https://github.com/prime-radiant-inc/serf)

<p class="repo-desc">A non-interactive coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="serf" week="2026-07-13" />
