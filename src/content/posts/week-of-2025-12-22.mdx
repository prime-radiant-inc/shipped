This is where the company's public record starts: the week **prime-radiant-inc**'s first repository, **streamlinear**, landed — a Model Context Protocol tool that hands an agent a clean interface to Linear. Around it, the obra ecosystem kept moving, with **superpowers** cutting two releases and outside contributors landing fixes across half a dozen repos.

## Featured

<article class="repo">

### [prime-radiant-inc/streamlinear](https://github.com/prime-radiant-inc/streamlinear)

<p class="repo-desc">A Model Context Protocol tool that gives a coding agent a clean interface to Linear.</p>

<RepoStat org="prime-radiant-inc" name="streamlinear" week="2025-12-22" />

Fourteen commits from a standing start — the repo's first commit through a working, npx-installable MCP tool. The arc: a `searchIssues` fix (use `term`, not `query`), a discoverability pass (me/help actions, better errors, and teams/states baked into the tool description at startup so an agent sees them without a round-trip), and npx packaging — a pre-commit hook that auto-builds and commits `dist/`, plus a `bin` field and shebang. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [obra/superpowers](https://github.com/obra/superpowers)

<p class="repo-desc">An agentic skills framework and software-development methodology.</p>

<RepoStat org="obra" name="superpowers" week="2025-12-22" />

Ten commits and two releases (`v4.0.2`, `v4.0.3`). The work sharpened the framework's edges: slash commands made user-only via `disable-model-invocation`, agent-model inheritance fixed, `git check-ignore` adopted for worktree gitignore verification, and guidance added to the writing-skills and using-superpowers skills (automation-over-documentation, stronger handling of explicit skill requests). Jesse Vincent drove it; outside contributors **egornomic** and **mycarrysun** each landed a commit.

</article>
