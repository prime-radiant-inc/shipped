<section class="summary">

Two threads ran through the week. One was a new native app — **clearance**, a local-first macOS markdown editor — going from an empty repo to a tagged v1.1.0 in seven days. The other was agent *evaluation*: **serf** poured most of its week into an eval dashboard and a trajectory-export format, a new harness called **gauntlet** appeared, and the dashboard itself was spun out into its own repo. Underneath it all, **sprout** kept 165 commits of self-improvement work moving.

## Featured

<article class="repo">

### [prime-radiant-inc/sprout](https://github.com/prime-radiant-inc/sprout)

<p class="repo-desc">A self-improving agent framework that detects its own failures and rewrites its genome to avoid them.</p>

165 commits, centered on a genome restructure: a `rootDir` + overlay resolution model for merged agent lookup, per-project genome data directories, and export-learnings simplified to overlay-only resolution — all pushed through several rounds of code review. Alongside the plumbing came safety work: guardrails injected dynamically into system prompts at the tool boundary, a fix preventing agent hallucination when tool resolution returns zero tools, support for workspace-tool-only agents, and a project-memory agent added to the root agent tree.

### [prime-radiant-inc/clearance](https://github.com/prime-radiant-inc/clearance)

<p class="repo-desc">A native macOS markdown editor — local-first, with a network-blocked rendering view.</p>

A new app that shipped fast: 93 commits from "bootstrap clearance macos app" through a string of releases ending at v1.1.0. Along the way it grew a recent-files model, markdown frontmatter parsing and a rendered view with a frontmatter table, a CodeMirror editor with syntax highlighting (assets vendored for a fully local editor), a solarized light/dark theme, drag-to-popout windows with disk-change reload, and a security posture that blocks network resources in both the rendered view and the runtime webview. Outside contributors **acme** (2 commits) and **rodbegbie** (1) pitched in.

<article class="repo">

### [prime-radiant-inc/serf](https://github.com/prime-radiant-inc/serf)

<p class="repo-desc">An agent framework in Go — this week, mostly its evaluation dashboard and trajectory export.</p>

85 commits, with staff engineer **Drew Ritter** contributing 9. The bulk went into the eval dashboard: proper task-lifecycle states (queued/running/verifying/pass/fail), run metadata and task deduplication, tool-call duration instrumentation surfaced in trajectories, and detecting task status from agent output rather than result-file timestamps. The other strand was ATIF — a native trajectory-export format — with v1.6 types, a converter handling thinking blocks and redacted content, and an `--export-atif` flag that writes a trajectory at session close for the harbor viewer.

### [prime-radiant-inc/gauntlet](https://github.com/prime-radiant-inc/gauntlet)

<p class="repo-desc">An LLM-agent evaluation harness ("vet") — runs scenarios against agents through CLI, web, and TUI adapters.</p>

A new project, 63 commits from design doc to a working harness: a story-card parser, an evidence logger, an LLM provider abstraction (Anthropic + OpenAI), and three adapters — a subprocess CLI adapter, a web adapter wrapping a forked superpowers-chrome CDP library, and a TUI adapter driving tmux sessions. It also gained an API server with scenario CRUD, containerized execution via Docker, a "fanout" generator for producing scenario variations, and the beginnings of a React UI.
