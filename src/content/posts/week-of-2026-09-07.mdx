Three new repos in one week, all from the same shop: **`prime-radiant-inc/study-skills`** (a Claude Code plugin for durable agent learning), **`prime-radiant-inc/shepherd-pr`** (a portable plugin for shepherding PRs through CI and review), and **`obra/scan-to-model`** (scan-reconstruction skills and tools for Codex and Blender). Alongside them, **`obra/episodic-memory`** cuts two releases on the same day — v1.5.0 and v1.6.0 — adding a fifth conversation-harness integration and an index-bloat guard. Underneath all of that, **`prime-radiant-inc/evener`** is the busiest repo again, and for the first time in a few weeks brings in outside contributors rather than staying entirely in-house.

<article class="repo">

### [obra/episodic-memory](https://github.com/obra/episodic-memory)

<p class="repo-desc">MCP server giving Claude a persistent, searchable memory of past conversations (no repository description set).</p>

<RepoStat org="obra" name="episodic-memory" week="2026-09-07" />

Two releases, same day. v1.5.0 added Cursor and opencode harness support, isolated the summarizer subprocess from the user's own MCP servers and settings, and made sidechain conversations searchable. v1.6.0 followed with a fifth conversation harness (Oh My Pi), an `EPISODIC_MEMORY_DISABLE_AUTO_SYNC` off-switch, AWS Bedrock summarization passthrough, and a guard against index bloat from oversize single messages. Underneath both: consolidated summarizer error handling (timeouts, fallbacks, a warning on metered APIs), safer install/db behavior (verifying the native binding actually loads instead of trusting exit codes; a `busy_timeout` for multi-writer safety), and CI now building and testing every PR — including from forks — on both Node 22 and 24. Contributors: **Jesse Vincent (staff)**, the large majority, plus **Ada Sen (staff)**, and one test-suite fix from outside contributor **Victor Naumik** (`vicnaum`).

</article>
