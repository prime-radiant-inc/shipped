### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-08-31" />

By far the most active repo this week, with broad simultaneous work across the hub, agent, and web layers. The headline is a models.dev-backed provider registry cut over as a flag-day migration, landing a new `providers.toml` schema with an auto-conversion path from the old one. Alongside it: per-connection serial worker dispatch for the app server, unified tool-call disclosure and verbosity controls in the web UI, job_watch timers, and delegate task-list handling (presence-based add/update, seeded task lists). Underneath, a long tail of hardening: drain/completion race fixes, scratch-disposal cleanup, credential-leak guards (never harvest a credential carried in a URL path; stop echoing pasted secrets from malformed refs), mobile web fixes (composer above the keyboard, larger tap targets), and test-suite robustness work (real-completion waits, ETXTBSY guards, deterministic cancel classification). Contributor: **Jesse Vincent (staff)**, with one `dependabot[bot]` dependency-bump commit.

</article>

<p class="repo-desc">Behavioral eval lab (Quorum) for the superpowers project that drives real coding-agent CLIs through a QA agent and grades them on workflow compliance.</p>

<RepoStat org="prime-radiant-inc" name="superpowers-evals" week="2026-08-31" />

The second-most active repo this week, all direct pushes rather than merged PRs. One continuous campaign-infrastructure arc: sealing a multiharness signature campaign (frontier and open models, later adjusting the model roster), and a frontier and open models signature campaign run through two launches — one cancelled on platform findings, one sealed. Underneath both, a run of fixes to the campaign "seal act" (digest-verified regeneration, atomic markdown-then-JSON publication, sealed-state preservation across a post-append cancel race, orphan-kill and verified-death reaching the tmux subject host), credential routing for Bedrock-backed graders, and a new "descriptive fold" report schema (counts, medians, contention counters, provenance findings). Sole author: **Drew Ritter (staff)**.
