A dense week. **winpepper** — Windows-native local dictation — was created and built out through numbered milestones in seven days, all of it staff-authored before outside contributors join later. **claude-session-driver** cut a real `v2.0.0`, dropping its "fake tool-approval gate," and **episodic-memory** landed end-to-end Codex support across four point releases. The eval harness lifted into superpowers the week before split out into its own repo, **superpowers-evals**, and **superpowers-chrome** made browser-dialog handling a first-class concern.

## Featured

<article class="repo">

### [obra/claude-session-driver](https://github.com/obra/claude-session-driver)

<p class="repo-desc">Launch, control, and monitor other Claude Code sessions as workers via tmux.</p>

<RepoStat org="obra" name="claude-session-driver" week="2026-05-11" />

`v2.0.0` dropped the fake tool-approval gate; `v2.0.1` disallowed `AskUserQuestion` inside workers. In between came three rounds of user-feedback fixes: a universal worker handle, spec-aligned paths, status and handoff commands, and a default worker listing. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [obra/episodic-memory](https://github.com/obra/episodic-memory)

<p class="repo-desc">A memory and recall layer for coding-agent sessions.</p>

<RepoStat org="obra" name="episodic-memory" week="2026-05-11" />

Codex support landed end-to-end across four releases (`v1.3.0` → `v1.4.1`): transcript parsing, session summarization, plugin packaging, hook synchronicity, and production hardening (raw-HTML escaping, local-shell-output handling). On the reliability side, `v1.4.1` drained a zero-exchange sync backlog that had been silently stalling summarization, recall-trigger reliability improved, and the `/search-conversations` slash command was dropped. Jesse Vincent drove it; one commit came from outside contributor **`minyek`**.

</article>

<article class="repo">

### [obra/superpowers-chrome](https://github.com/obra/superpowers-chrome)

<p class="repo-desc">A Chrome-control plugin via the DevTools Protocol.</p>

<RepoStat org="obra" name="superpowers-chrome" week="2026-05-11" />

`v2.1.0` made dialog handling first-class: a `DialogRefusedError` thrown rather than silently swallowed on browser dialogs, a permission shim registered at attach, dialog-awareness threaded through the mouse / keyboard / capture / CDP-connection attachers, and Tier-C smoke tests against real Chrome. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [obra/winpepper](https://github.com/obra/winpepper)

<p class="repo-desc">Windows-native local dictation — hold a hotkey, speak, release. Parakeet TDT v3 ASR plus LlamaSharp cleanup, entirely local.</p>

<RepoStat org="obra" name="winpepper" week="2026-05-11" />

This is winpepper's creation week — and unlike every later week already covered on this blog, all of it is Jesse Vincent, before the outside contributors arrive. The README is loud about its own provenance ("entirely agentic, never human-tested"), and the tool was built out in plan-numbered milestones in a single week: Plan 4 (history / lab / models tab plus a downloader), Plan 5 (post-paste learning, a Diagnostics page, crash handling via `MiniDumpWriter`), and Plan 6 (WiX MSI packaging, autostart, a code-signing wrapper, nightly CI smoke), cutting a `v0.6.0-alpha`. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [prime-radiant-inc/superpowers-evals](https://github.com/prime-radiant-inc/superpowers-evals)

<p class="repo-desc">A behavioral eval lab (Quorum) for the superpowers project.</p>

<RepoStat org="prime-radiant-inc" name="superpowers-evals" week="2026-05-11" />

Split out this week from the `drill`/`evals/` harness that had been lifted into superpowers the week before. It shipped a Codex-native-hook eval backend and Pi backend support in the same week, plus initial security hardening — one of three merged PRs explicitly targeting Codex security controls ahead of wider use. Contributors: Drew Ritter and Matt Windbrook.

</article>
