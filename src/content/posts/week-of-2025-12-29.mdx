## Featured

<article class="repo">

### [obra/lace](https://github.com/obra/lace)

<p class="repo-desc">An agent runtime — the harness that runs coding-agent sessions.</p>

<RepoStat org="obra" name="lace" week="2025-12-29" />

The week lace took shape: 155 commits building the runtime from its protocol upward. The `ent-protocol` package landed first — NDJSON-over-stdio JSON-RPC with zod method schemas — then `lace-agent` (initialize, session/new, a permission-gated `shell.exec`) and a `supervisor` to spawn and manage multiple agent processes per workspace. A Rust `ratatui` TUI grew in parallel: headless app state and reducer, an interactive loop, a command palette and help overlay, a session picker, a provider/model configure wizard, search-and-jump, and theming. Session lifecycle picked up checkpoint, rewind, and compaction (ported from core's strategies), and the `delegate` tool arrived as subagent jobs. Along the way the old Tasks feature, the legacy session runtime, and better-sqlite3 were all removed. Sole contributor: Jesse Vincent.

</article>

<article class="repo">

### [obra/winby](https://github.com/obra/winby)

<p class="repo-desc">A macOS window manager and window switcher.</p>

<RepoStat org="obra" name="winby" week="2025-12-29" />

Initial commit to `v1.3.1` across eight releases in the week. Cmd+Tab interception and window cycling came first, then tab clustering with aggressive focus handling (direct AX API, synthetic-click fallback), browser and Terminal tab support, and multi-space window capture — including minimized and other-space windows via `CGSHWCaptureWindowList`. Sparkle auto-updates, a first-run onboarding flow, and a promotional landing page shipped alongside. A late refactor split the monolith into views, managers, and focused extensions, and `v1.3.0` added OCR content search plus a privacy pass that blocks all introspection of sensitive apps like password managers and eliminates idle CPU usage. Sole contributor: Jesse Vincent.

</article>
