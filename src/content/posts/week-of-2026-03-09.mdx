A release-heavy week. **superpowers** crossed into v5.0 — three releases in seven days — with a visible surge of outside contributors. **sprout** taught itself to price its own token usage from live data, and **stockyard** returned with low-level VM infrastructure: a custom Firecracker kernel and an arbitrary-command execution system.

## Featured

<article class="repo">

### [obra/superpowers](https://github.com/obra/superpowers)

<p class="repo-desc">An agentic skills framework and software-development methodology.</p>

The week's biggest community moment: superpowers shipped **v5.0.0** — visual brainstorming, document review loops, architecture guidance — followed quickly by v5.0.1 and v5.0.2. Highlights included a native Gemini CLI extension (replacing an MCP server), a rewrite of the brainstorm server to zero runtime dependencies, subagent context-isolation principles across the delegation skills, and a run of cross-platform hook fixes spanning Windows, Linux, and bash 5.3+. Jesse wrote the bulk (47 commits), with a steady stream of outside help: **savvyinsight** and **mvanhorn** (2 each), plus **ynyyn**, **samuelcsouza**, and **daniel-graham**; staff engineer **Drew Ritter** contributed one. (Line counts are suppressed here — a large swing in the diff is a vendored-dependency swap, not authored code.)

### [prime-radiant-inc/sprout](https://github.com/prime-radiant-inc/sprout)

<p class="repo-desc">A self-improving agent framework that detects its own failures and rewrites its genome to avoid them.</p>

116 commits. The headline feature was live model pricing: OpenRouter added as a pricing source with dual-source fetching, a cache-fallback path, cached-token pricing folded into cost computation, and the pricing table threaded through the WebSocket snapshot to the web client. Elsewhere sprout gained human-friendly mnemonic names for agents (shown in the sidebar, thread header, and delegation cards), inactivity-based agent timeouts built on `AbortController`, and a batch of TUI and web display refinements.

<article class="repo">

### [prime-radiant-inc/stockyard](https://github.com/prime-radiant-inc/stockyard)

<p class="repo-desc">A microVM-orchestration daemon — ZFS-backed, Firecracker VMs managed over gRPC.</p>

39 commits, all from staff engineer **Matt Windbrook**. Low-level infrastructure work: a custom Firecracker kernel built with TUN and nftables support, ephemeral Tailscale nodes for VMs, and native Claude Code installed into each VM. The larger effort was a command-queue system — a SQLite-backed schedule of arbitrary commands executed in VMs over vsock, with privilege dropping, gRPC handlers, and matching CLI subcommands — which also let the daemon shed its old coupling to a specific git repo and ref.
