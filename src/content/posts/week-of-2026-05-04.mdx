A week of standing things up and shipping them immediately. **bot-toolkit** — a reusable TypeScript core for building unattended Claude-powered chat agents — was created and published to npm in the same seven days, and **parallel-adversarial-review** appeared as a pair of adversarial code-review skills, complete with a self-review pass using its own tooling. Alongside the launches, **superpowers** cut `v5.1.0` and lifted a `drill` eval tool into an `evals/` harness — the seed of the standalone eval lab that splits out the following week — and **streamlinear** shipped its first npm-packaged release.

### [prime-radiant-inc/bot-toolkit](https://github.com/prime-radiant-inc/bot-toolkit)

<p class="repo-desc">A reusable TypeScript core for building unattended, Claude-powered chat agents.</p>

<RepoStat org="prime-radiant-inc" name="bot-toolkit" week="2026-05-04" />

Stood up and shipped to npm in the same week (`v1.0.0`, then `v1.0.1`): sealed public SDK and route boundaries, an allowlisted Claude-SDK environment, npm-provenance-gated release publishing, and a public-package quality gate in CI. Sole contributor: Drew Ritter (staff).

### [prime-radiant-inc/parallel-adversarial-review](https://github.com/prime-radiant-inc/parallel-adversarial-review)

<p class="repo-desc">Two Claude Code skills for adversarial code review — single-model (PAR) and multi-model with cross-critique (MMAR) to catch hallucinations — plus a fixture-based eval suite.</p>

<RepoStat org="prime-radiant-inc" name="parallel-adversarial-review" week="2026-05-04" />

New this week: the initial plugin commit, then a same-week self-review pass that ran the plugin's own MMAR review against itself and applied the findings, and an adapter-roster update (dropped aider and cursor-agent, added Pi and Droid). Sole contributor: Jesse Vincent (staff).

</article>
