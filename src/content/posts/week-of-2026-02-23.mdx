<section class="summary">

The busiest week in the entire backfill, driven by one repo. **sprout** — a from-scratch agent framework that watches its own failures and rewrites itself to avoid them — landed 545 commits in seven days, more than any other repo-week we've recorded. Around it, **serf** grew a real terminal UI, the **engineering-notebook** got a ground-up redesign, and a scatter of new plugins and single-purpose tools shipped across both orgs.

## Featured

<article class="repo">

### [prime-radiant-inc/sprout](https://github.com/prime-radiant-inc/sprout)

<p class="repo-desc">A self-improving agent framework: it detects its own "stumbles" — retries, repeated tool calls, dead ends — and rewrites its genome to avoid repeating them.</p>

545 commits in a single week — the largest repo-week in the backfill. The work is visibly spec-driven, with commit after commit citing section numbers: retry-stumble detection (§7.3), improvement evaluation that compares stumble rates before and after a change (§8.6), concurrent delegation (§2.5), an immutable kernel that rejects agent names shadowing primitives, and a collapse of per-agent tools down to a single `delegate` primitive restricted to subagents. Midweek it grew an interactive terminal — Ink/React, a model picker, ULID-based session IDs, a session picker, and scroll-mode indicators. (Line counts are suppressed for this card: a large block of the diff is recorded VCR test cassettes, not hand-authored code.)

<article class="repo">

### [prime-radiant-inc/serf](https://github.com/prime-radiant-inc/serf)

<p class="repo-desc">An agent framework in Go — the runtime, prompt engineering, and now a terminal UI.</p>

127 commits of steady building. A heavy strand of prompt engineering — capability-confidence logging, an "analysis paralysis circuit breaker," adversarial self-review, TDD enforcement against pre-judging a task infeasible, and a running theme that every task is solvable and should be decomposed rather than declared impossible. On the runtime side: parallel tool calls for OpenAI, superpowers skills embedded directly into the binary, a ModelPicker and `/model` command, session-identity reset via `/clear`, AbortSignal threaded through primitive execution, and resumed-conversation history in the TUI.

<RepoStat org="prime-radiant-inc" name="serf" week="2026-02-23" />

</article>

<article class="repo">

### [prime-radiant-inc/engineering-notebook](https://github.com/prime-radiant-inc/engineering-notebook)

<p class="repo-desc">A local tool that turns agent session transcripts into a searchable, summarized journal.</p>

30 commits and a full UX redesign: a three-panel layout shell with an "Ink & Paper" style, rewritten conversation, journal, and project views wired together with HTMX partial routes. It also learned to extract "open questions" during summarization and surface them in entry cards, to skip non-journal-worthy and sub-agent sessions, and to ingest Codex sessions. A calendar Gantt view with an iCal feed landed, and the project was prepared for open-source release.
