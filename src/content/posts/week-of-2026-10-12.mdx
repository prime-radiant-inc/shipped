**`prime-radiant-inc/evener`** tags v0.3.8 this week, after a week running a sustained "copy-oracle" test-hardening campaign alongside a web-UI widget-library migration, device-pairing work, and an incrementally hardened per-test timing gate. A new repo, **`prime-radiant-inc/evener-client-playdate`**, also debuts this week as a native Playdate handheld client for evener, with voice composition and direct Tailscale connectivity. This week is still open: the data below runs through Friday evening, not the full calendar week.

## Featured

<article class="repo">

### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-10-12" />

Tagged release v0.3.8. By far the most active repo this week. The work clusters into a few sustained threads rather than one single feature: a **large "copy-oracle" test-hardening campaign** spanning nearly the whole week and touching web, native, hub, agent, TUI, sandbox, frontend, and appwire-client tests — converting assertions on literal copy/wording into assertions on structural state, markers, error sentinels/types, or toast kinds, backed by new tooling to catch regressions of the same kind (a copy-oracle inventory of wording-only tests, a CI ratchet against new ones, and that inventory tool itself later ported from Python to Go and TypeScript); a **web-UI migration onto the shared widget library**, done in explicit waves with a final follow-up and "last leftovers" pass; **device/mobile pairing work** (shared device invitations plus native Hub pairing, pairing destinations kept visible on narrow screens, automatic Hub-destination discovery for mobile pairing, clarified phone QR/sound-pairing codes); a **per-test timing "gate" hardened incrementally** to fail loudly on a malformed testing-budget config instead of silently, then segmented by test class, with some runner-bound classes returned to warn-only per a dated ruling; and **entry-backed background transcripts**, landed as a feature and then followed by a repair pass for defects the review found. Alongside those: memory work (pages that say when to recall themselves, a `memory_write` taking `when`/`body` fields, index lines linking the page path instead of the title), execenv/sandbox read-capping, several LLM/vision provider fixes, hub reliability fixes, and a run of changes landing right at the window's close: Stop taking the composer's slot with the status line lifting to the title, a floating compose button on the Board replacing its bottom bar, the session UI trimmed (dropping the like-this control for a copyable id and a smaller composer), settings reorganized with plugin sources unified, and delegate report messages preserved in more detail. Sole author: **Jesse Vincent (staff, `obra`)**.

</article>

<RepoStat org="prime-radiant-inc" name="evener-client-playdate" week="2026-10-12" />

A new repo, created this week — a native client for the Playdate handheld, built out through a series of same-day-merged PRs: an initial qualified import of the client made independent of the main evener checkout, then a run of pairing work (a shared full device-pairing fingerprint, documented automatic Hub destinations, clarified sound-pairing comparison codes), investigating and fixing Playdate TCP stalls with work preserved across runtime recovery, reduced read/send delays and idle redraws, conversation content loaded through history-inclusion flags, longer conversations made readable sooner with adjustable text, microphone-input display during setup-sound pairing, acoustic setup decoded across symbol-timing offsets, and — toward the end of the window — a recorded onboarding walkthrough, promo footage rendered from captured clips, the Playdate crank rendered in its correct side-wall plane, and both films embedded as inline README video players. No releases yet. Sole author: **Jesse Vincent (staff, `obra`)**.
