## Featured

<article class="repo">

### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-10-05" />

Tagged release v0.3.7 (a bare version-number release, no further release-note text — same pattern as prior evener releases). The week's PRs cluster into a few finished threads rather than one single feature: a **generated memory index**, built out end-to-end as a numbered series through its final review-fixes pass — memory pages now project an index generated from page frontmatter instead of a hand-written one, with overflow handling, a size cap, and the index gated on whether the skill it points to is actually loadable; two of the three PRs in a **notification-semantics cleanup** — a reply is only treated as "needs your reply" when it reads like an actual question, a plain reply no longer notifies, and a "needs response" state now waits out a quiet period before resting instead of firing immediately; and a **delegate reply-threading fix cluster** — a `delegate_send` reply or wait can now carry earlier queued results instead of losing them, delegate updates route to each live ancestor subagent's own thread, and a nested stable delegate is correctly attributed to its parent delegate's session. Alongside those: a broad native test-hardening pass wrapping previously-unwrapped synchronous store updates across many screens, dropping the Board's manual "mark as read"/"mark as unread" controls now that read-state tracks automatically on the phone, a fix for reading a `SKILL.md` missing its opening frontmatter delimiter, and further iPhone-redesign spec cleanup. Sole author: **Jesse Vincent (staff)**.

</article>

<article class="repo">

### [obra/superpowers-chrome](https://github.com/obra/superpowers-chrome)

<p class="repo-desc">Claude Code plugin for direct Chrome browser control via DevTools Protocol — zero dependencies.</p>

<RepoStat org="obra" name="superpowers-chrome" week="2026-10-05" />

Tagged release v3.0.11, "Default redaction for secrets present at page load; known-sensitive URLs suppressed outright." Secrets visible at page *load* time — a hidden `#init_key_code` field, and known-sensitive URLs — weren't being redacted by default, relying instead on capture logic that only triggered later in a session; now both are suppressed outright, with new test coverage added for the credential guard, the HTML-scrub page script, the secret-pattern matcher, and the sensitive-URL matcher. Sole author: **Ada Sen (staff)**. Several other PRs remain open but unmerged this window, including two of Ada Sen's own follow-ups and an outside contributor's long-standing `CHROME_WS_HEADLESS` addition — not counted as shipped since nothing of theirs merged this window.

</article>

### [obra/morning-routine-board](https://github.com/obra/morning-routine-board)

<p class="repo-desc">Morning routine checklist for two kids on a wall-mounted iPad.</p>

<RepoStat org="obra" name="morning-routine-board" week="2026-10-05" />

A new repo, created this week — a personal project, not a company product, built essentially start-to-finish in a single day: a config model for kids and tasks, a localStorage-backed store for config and daily check-offs, day-boundary logic for when the board resets, a board view-model and screen with a daily reset, a hidden settings screen behind a long-press gesture, offline support via a service worker plus Home Screen metadata, a README with iPad setup and deploy notes, and a same-day review-findings fix (single service-worker registration, a storage-access guard, a Safari 12 settings-launch fix). Committed directly, no PRs, no releases. Sole author: **Jesse Vincent (staff)**.
