## Featured

<article class="repo">

### [prime-radiant-inc/evener](https://github.com/prime-radiant-inc/evener)

<p class="repo-desc">A coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done, using native tool-calling across OpenAI, Anthropic, and Google models.</p>

<RepoStat org="prime-radiant-inc" name="evener" week="2026-11-09" />

Seven tagged patch releases (**v0.3.24** through **v0.3.30**), each a bare version tag with GitHub's auto-generated changelog. A hub/plugin-UI unification thread runs through the week: one marketplace screen for installing plugins and managing their sources, and plugin details that now expand inline instead of opening a slide-out sheet. Web and native converge on a shared design: one palette across both surfaces, the resting composer folding to one line, a single pending-message stack for undelivered messages, and native landscape support with safe-area insets (including dual-display iPhones). The voice surface consolidates to one status line and one action. Agent-side reliability work continues: coordinating rate-limit storms across sessions, waiting for quota instead of re-kicking failing turns, telling callers how to recover a failed model provider, and configurable per-model context-compaction thresholds. A large tail of fixes and tests runs across agent, web, hub, native, sandbox, execenv, and CI lanes. In-org author: **Jesse Vincent (staff, `obra`)**, plus outside contributions from **NopeCharon** (Asish), **jay23606** (Jay), and **mikemikimike**, and routine `dependabot[bot]` version bumps.

</article>

<article class="repo">

### [prime-radiant-inc/external-sandbox-pi](https://github.com/prime-radiant-inc/external-sandbox-pi)

<p class="repo-desc">Pi extension that runs Pi's coding tools and ! commands inside an External Sandbox</p>

<RepoStat org="prime-radiant-inc" name="external-sandbox-pi" week="2026-11-09" />

A brand-new repo: a Pi coding-agent extension that routes Pi's `bash`, `read`, `write`, `edit`, `grep`, `find`, and `ls` tools, plus the user's `!` commands, through an External Sandbox server over its health and exec-websocket protocol, and fails closed when the sandbox is unavailable. Built for Pi 1.5, with tests covering the protocol client, the guest helper, the extension itself, and end-to-end runs against the real Pi using a scripted model. Small follow-ups tightened an error message's punctuation and added, then trimmed, README badges pending an actual GitHub release to link to. Sole author: **Simon Willison (staff, `simonw`)**.

</article>
