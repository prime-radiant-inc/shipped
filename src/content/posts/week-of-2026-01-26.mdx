## Featured

<article class="repo">

### [obra/moltipass](https://github.com/obra/moltipass)

<p class="repo-desc">A SwiftUI iOS client for the Moltbook social network, built with xtool.</p>

<RepoStat org="obra" name="moltipass" week="2026-01-26" />

The week's biggest new thing — Jesse Vincent took it from empty project to a working app across forty-seven commits: a `KeychainService` for secure credentials, the full API layer (feed, posts, comments, voting, submolts, search, profile), the whole view stack from Welcome and Registration through feed, post detail, and profiles, session persistence, an app icon, and a build script — plus the steady round of fixes to match the real Moltbook API shape.

</article>

<article class="repo">

### [prime-radiant-inc/scribble](https://github.com/prime-radiant-inc/scribble)

<p class="repo-desc">A Slack-native assistant bot — the coworker that lives in the workspace.</p>

<RepoStat org="prime-radiant-inc" name="scribble" week="2026-01-26" />

Scribble kept maturing into the assistant it was becoming. This week it migrated onto a shared `bot-toolkit` submodule and the Claude Agent SDK, restructured conversation logging into a main/thread split, and grew a `ScribbleOrchestrator` with dual-session logic and an explicit engagement schema — so the bot decides *whether* to respond before it does, replies in-thread under the triggering message, and injects cross-channel context in the background. Session files and config were moved onto EFS for durability. Fifty-five commits, all Jesse Vincent.

</article>

<article class="repo">

### [prime-radiant-inc/llm-proxy](https://github.com/prime-radiant-inc/llm-proxy)

<p class="repo-desc">A Go reverse proxy that sits in front of LLM APIs and logs the traffic.</p>

<RepoStat org="prime-radiant-inc" name="llm-proxy" week="2026-01-26" />

A remarkable cadence — five tagged releases from `v0.2.1` through `v0.6.0` in a single week. The throughline was agent observability: a container image published to GHCR, extended Loki labels for richer Grafana queries, pattern-state persistence, and an event-emission pipeline (with a SHA-256 request-body hash for deterministic replay) landing in `v0.6.0`. Fourteen commits from Drew Ritter, who kept the Homebrew tap tracking each bump.

</article>
