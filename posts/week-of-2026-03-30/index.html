hearthstone builds a household RAG, mutter-butter stamps your windows

Week of March 30, 2026 · Mar 30, 2026–Apr 5, 2026 · published Apr 5, 2026

This was a from-scratch-products week. hearthstone went from its first commit to a working household knowledge assistant — a retrieval backend, a full iOS client, and an evaluation harness — in ninety commits. mutter-butter reimagined GNOME window management, turning minimized windows into draggable “stamps” on a shelf. And stockyard rebuilt its VM manager around a hypervisor-agnostic backend, then tuned a macOS microVM down to a 1.24-second cold boot to a live SSH session.

prime-radiant-inc/hearthstone

A household knowledge assistant — a retrieval service over your own documents, with an iOS client and a guest-sharing model.

90 commits

Ninety commits, starting from the repo’s very first, built an entire product end to end. The backend came up as a provider-abstracted embed/chat layer, a section-aware Markdown chunker that preserves tables and prepends heading breadcrumbs, vector search via sqlite-vec scoped per household, and Google Drive ingestion that exports docs and converts them to Markdown through Pandoc. Authentication evolved mid-week from Google sign-in to passkeys plus email verification, with owner JWTs and short-lived guest sessions. The iOS app landed in parallel: Keychain-backed token storage, an SSE client streaming chat deltas, a numbered-citation system that surfaces only the sources the model actually cited, and a read-only in-app viewer that scrolls to and highlights the cited passage. The week closed on evaluation — a retrieval harness comparing four strategies (plain RAG, multi-query, multi-document, and full-context), an LLM-as-judge scoring answers against key facts, and a GEPA-inspired prompt optimizer running all its questions in parallel. Sole contributor: Matt Windbrook. (Line counts are omitted for this repo — the diff is dominated by generated and vendored files, so a raw total would mislead more than it informs.)

obra/mutter-butter

A GNOME Shell extension that turns minimized windows into draggable “stamps” on a shelf and snaps live windows to a grid.

53 commits +7,170 −804

A new GNOME 50 extension that went through five rounds of design review before a line of implementation, then came together from focused subsystems: a grid engine with cell math and occupancy tracking, a focus-rank list, stamp-placement strategies, a scale manager handling clone lifecycle and auto-shrink, an input router with stable z-ordering and a reentrancy guard, and a drag handler that intercepts grab operations. The result is a window manager where minimized windows become “stamps” you drag around a shelf, live windows snap to a grid on any move, and dropping a window onto an occupied cell swaps the two. Sole contributor: Jesse Vincent.

prime-radiant-inc/stockyard

A VM manager for agent workloads.

34 commits +6,360 −527

Stockyard grew a hypervisor-agnostic backend — a VMBackend interface with adapters for Firecracker and, new this week, macOS via vfkit, plus a rootfs-provisioner interface with ZFS, copy-based, and APFS-clonefile implementations. The macOS path got an Alpine arm64 rootfs tuned hard for boot speed (kernel-level DHCP, static-IP VirtioFS, SIGKILL-based instant destroy), landing a 1.24-second cold boot to a running SSH session. Sole contributor: Matt Windbrook.
