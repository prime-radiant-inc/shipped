Featured

prime-radiant-inc/serf

An agent framework in Go — sessions, tools, multi-provider model adapters, and a benchmark harness.

120 commits +74,852 −2,567

serf’s largest week so far. It grew a real front end — a Bubble Tea terminal UI driven by an SSE server (ring buffer, reconnect catch-up, /status, /interrupt, /input), with a session picker, slash commands, theming, and rich tool renderers. Underneath, an append-only JSONL transcript system landed for durable session logging and transcript-based resume, including parent–child linkage for sub-agent transcripts. Live model listing arrived across the Anthropic, OpenAI, and Google adapters, the four-layer compaction collapsed to two, and a long run of prompt-and-steering work — TDD discipline, verification steps, content-filter recovery — came straight out of terminal-bench failure analysis.

prime-radiant-inc/sprout

A self-improving agent framework in TypeScript — agents that detect their own stumbles and rewrite a versioned “genome” to learn.

87 commits +19,583 −350

A brand-new project, built up phase by phase in 87 commits. It starts with a unified LLM client routing across native Anthropic, OpenAI, and Gemini adapters, then adds a core agent loop with delegation, a git-versioned Genome storing agents/routing/memories, keyword and embedding recall wired into the system prompt, and — the interesting part — a Learn process: it watches for “stumbles,” emits learn signals, and applies mutations to its own genome while the agent runs, with programmatic rollback and pruning.

prime-radiant-inc/engineering-notebook

A tool that ingests agent session logs into a searchable, day-by-day journal.

24 commits +5,175 −215

Also new this week: a Bun project that parses JSONL session logs, stores them in SQLite, summarizes them with an LLM, and serves the result as a Hono web app — a journal rendered as a day-by-day timeline, with conversations split on logical day boundaries rather than the wall clock.
