sprout builds a memory, ts-libghostty binds a terminal — and watches NetHack

Week of April 20, 2026 · Apr 20, 2026–Apr 26, 2026 · published Apr 26, 2026

The busiest week of the backfill. sprout built “mira,” a full agent-memory system, across ten phases and 143 commits — embeddings, vector search, extraction, consolidation, and a subcortical-recall prepass — then hardened it exhaustively. ts-libghostty went from nothing to a released TypeScript binding stack over Ghostty’s terminal engine, capped by a runner and an agent that watches an LLM play NetHack. gauntlet grew a full evidence-and-transcript system. And several tools were flattened, licensed, and pointed at a brand-new prime-radiant-marketplace for public release.

Featured

prime-radiant-inc/sprout

An experimental self-improving multi-agent coding system.

143 commits +23,707 −1,978

143 commits stood up “mira,” a memory and recall layer, in ten numbered phases: a memory foundation and index cache, an embedding-provider abstraction defaulting to a local model, SQLite vector search, extraction prompts with deduplication, a segment store that collapses sessions into memory segments, a surfacing pipeline with usage tracking, an archivist agent, a memory link graph, per-project scoring, consolidation maintenance, and an opt-in “subcortical recall” prepass. Most of the week, though, went into hardening it — dozens of commits scoping authorization, serializing index rebuilds, redacting secrets before collapse, healing pruned references, and gating memory mutations on trusted authorization. Sole contributor: Jesse Vincent.

prime-radiant-inc/ts-libghostty

TypeScript bindings around Ghostty’s VT state machine.

206 commits

206 commits, built pass by pass with an adversarial code review at each gate, carried ts-libghostty from a design spec to a released binding stack. Pass 1 established a lazy FFI loader with symbol-manifest verification, a Terminal class with zero-copy byte ingestion, and a Formatter; later passes added effect callbacks, a RenderState with hot-path cell iterators, and a KeyEncoder. The project restructured into a monorepo (libghostty-vt), shipped five point releases through v0.5.1, and grew two consumers: blinkyterm, a terminal-driving runner, and bobbihack, an agentic TUI that watches an LLM play NetHack in a rendered pane. Sole contributor: Matt Windbrook.
