prime-radiant-inc/agentic-usage-meter

A macOS menu-bar meter for coding-agent subscription quotas.

64 commits 🏷 6 releases +8,257 −999

A week of rapid iteration — six tagged releases, v0.1.1 through v0.2.4 — and the throughline is concurrency hardening, not a single feature. Every persisted-state write was serialized through one mutation queue, reconnect-refresh blocking was reference-counted, in-flight refreshes are now drained before a reconnect touches shared state, and account-removal and cancellation races got closed out. Along the way it also picked up multi-org accounts, a provider-request link, and Node 24 release artifacts. This is what fixing account-management race conditions under fast release cadence looks like.

obra/superpowers-chrome

A Claude Code plugin for direct Chrome control via the DevTools Protocol — zero dependencies.

24 commits 1 PR 🏷 3 releases +19,407 −9,107

Three releases in a week, each with a distinct character. v3.0.3 honors stringified-JSON payloads for structured actions (Postel’s law), with added behavioral test coverage. v3.0.4 was a dedicated security release, resolving every open Dependabot alert. v3.0.5 is reliability and hardening across the MCP and CLI launch paths: passing image-tool and port-lookup args directly instead of through a shell, reporting why Chrome failed to launch, keeping Chrome’s sandbox on except where it genuinely can’t work, surfacing spawn failures instead of crashing the server, and isolating test profile and cache paths from the user’s real cache dir.
