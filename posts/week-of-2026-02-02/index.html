Featured

prime-radiant-inc/claude-session-viewer

A web app for reading agent session transcripts — indexed, full-text-searchable, with sidechain visualization.

64 commits +15,480 −671

The centerpiece of the week — from scaffolding to a genuinely capable tool in sixty-four commits. A JSONL parser builds conversation threads; a directory scanner indexes projects, sessions, and subagents; and a SQLite database with FTS5 gives full-text search. On top of that came sidechain visualization (a tree structure for alternate conversation branches with a branch-point switcher and a minimap), multi-user support keyed by hostname, a Codex session parser and importer with its own tool renderers, message permalinks, secret masking, and an admin mode for hiding noise. All sixty-four commits from Jesse Vincent.

obra/superpowers

An agentic skills framework and software-development methodology.

15 commits 3 PRs +440 −736

Shipped v4.2.0, focused on Windows and Codex: async SessionStart hooks to stop a Windows terminal freeze, $HOME-based path expansion, an O(n²) escape routine replaced with parameter substitution, and a minimal Codex installer for native skill discovery that let the project drop its bootstrap CLI and gatekeeper entirely. Eleven of the fifteen commits came from Drew Ritter, four from Jesse Vincent.

prime-radiant-inc/scenarios

A prompt-injection test suite for LLM agents.

8 commits 3 PRs +1,914 −393

Matured from prototype into a real security test suite — redesigning its email scenario around subtle social engineering, adding calendar-assistant and support-assistant injection scenarios with model scoreboards (GPT 4.1 failing several, GPT 5.2 blocking all), and exposing every scenario tool through an MCP server. Simon Willison led the work.
