books-for-bots arrives, episodic-memory hotfixes

Week of April 27, 2026 · Apr 27, 2026–May 3, 2026 · published May 3, 2026

Two things anchor the week. episodic-memory — the memory/recall layer for coding-agent sessions — shipped three tagged releases in seven days, the last of them an emergency hotfix for a recursive process cascade. And books-for-bots appeared from nothing: a Rust CLI that flattens an EPUB into a single YAML-headed Markdown file with per-chapter byte and line offsets, giving an agent a navigation API for token-efficient reading. Around the two, outside contributors turned up early — one-PR fixes on episodic-memory and the bulk of a whole fork’s week on ghost-pepper.

obra/episodic-memory

A memory and recall layer for coding-agent sessions — searchable session history with semantic recall.

11 commits 2 PRs 🏷 3 releases +24,591 −10,292

Three tagged releases in one week (v1.1.0 → v1.1.1 → v1.1.2), the last a same-day emergency hotfix for a recursive process cascade. The feature work: search filters by project, session, and git branch; a schema migration; and a summarizer-hygiene pass that stopped polluting ~/.claude/projects with summarizer session JSONLs and added a cascade-delete on the tool-calls foreign key. v1.1.1 folded version numbers down to a single source of truth. Jesse Vincent drove the week; two outside contributors each landed a PR — Matt Van Horn (mvanhorn) fixed an npm-install flag, and Asish Kumar (officialasishkumar) fixed Windows SessionStart-hook path quoting.

prime-radiant-inc/books-for-bots

A Rust CLI that converts EPUBs into a single YAML-headed Markdown file with per-chapter byte and line offsets — a navigation API that lets an LLM agent read a book token-efficiently.

44 commits +10,959 −288

New this week, and shipped a full v1 in a single push: heading and whitespace normalization, duplicate-heading and running-header detection, cross-chapter link slugging, byte/line offset verification, and a determinism test that runs the conversion twice and asserts the output is byte-identical. Project Gutenberg’s Alice in Wonderland rides along as the in-repo example. Sole contributor: Jesse Vincent.
