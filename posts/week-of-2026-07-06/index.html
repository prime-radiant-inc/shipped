First releases: books-for-bots, obol, and teststrip go public

Week of July 6, 2026 · Jul 6, 2026–Jul 12, 2026 · published Jul 12, 2026

Featured

prime-radiant-inc/books-for-bots

A Rust CLI that converts EPUBs into a single YAML-headed Markdown file with per-chapter byte and line offsets — a navigation API that lets an LLM agent read a book token-efficiently.

8 commits 🏷 2 releases +1,348 −373

books-for-bots shipped its first tagged releases this week. v0.1.0 brought a CI and tag-triggered release workflow that builds binaries for six platforms, plus an MIT license and a clippy/cargo fmt cleanup so CI can enforce lint and formatting going forward. The v0.1.1 follow-up added a --version flag so an agent can self-identify its build, fixed EPUB-internal path normalization at the load boundary, and retired a dead macOS CI runner label. Small, but it’s now a tool you can pin a version of.

prime-radiant-inc/obol

Read an AI-agent transcript and estimate what it cost — a Rust core with C-ABI bindings for Python, Go, and TypeScript (Bun and Node).

2 commits 🏷 v0.7.0 +10,873 −9,097

obol’s v0.7.0 is a pure pricing-data release: it refreshes the bundled model-price snapshot and adds claude-sonnet-5 pricing, so cost estimates stay accurate as the model lineup moves.

prime-radiant-inc/teststrip

A macOS photo-culling app — catalog-first, non-destructive, AI-assisted. Early development; not ready for use.

675 commits 🏷 2 releases +120,023 −12,756

teststrip went public this week and cut its first releases — a models-v1 model-asset release and a v0.1.0 app build. (The repo object was created this week, but the project already had a full week of history behind it; read this as “went public,” not “started.”) The week’s work hardened the import pipeline for trust: preflight free-space checks before a card import, heartbeated import/scan progress so the watchdog survives slow phases, a persisted default import destination, and a time-bounded preview scan so the photo count it shows you is accurate. Alongside that, security-scoped source bookmarks now persist, restore, and repair themselves across reconnects and relaunches, and the culling signals grew up — Apple feature-print extraction wired into similarity filters, signal-backed similarity stacks, and provider-driven Smart Collection and keyword suggestions.

prime-radiant-inc/serf

A non-interactive coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done — native tool-calling across OpenAI, Anthropic, and Google models.

971 commits +228,828 −18,735

serf’s dominant thread this week was a fuzz-coverage completion campaign: closing fuzz-reachable coverage gaps package by package — agent, hub, doctor, contextmgr, execenv, TUI, appsource, jobstore — toward an exact-coverage target. The second real feature line was model-switching: validating a switch up front, gating it on turn state, broadcasting model and effort changes, persisting switch markers, and enforcing replay provenance when a session changes model mid-run. Some mobile-web polish for the spawn UI landed too (viewport handling, composer dock anchoring) — real, but a footnote next to the coverage push.
