prime-radiant-inc/streamlinear

A Model Context Protocol tool that gives a coding agent a clean interface to Linear.

14 commits

Fourteen commits from a standing start — the repo’s first commit through a working, npx-installable MCP tool. The arc: a searchIssues fix (use term, not query), a discoverability pass (me/help actions, better errors, and teams/states baked into the tool description at startup so an agent sees them without a round-trip), and npx packaging — a pre-commit hook that auto-builds and commits dist/, plus a bin field and shebang. Sole contributor: Jesse Vincent.
