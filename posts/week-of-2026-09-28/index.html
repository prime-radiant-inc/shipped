obra/superpowers-chrome

Claude Code plugin for direct Chrome browser control via DevTools Protocol — zero dependencies.

2 commits 2 PRs 🏷 v3.0.8 +2,379 −134

Tagged release v3.0.8. The existing data-sen-secret DOM-marker guard only caught credential-shaped content when a caller read back full serialized HTML, so eval, extract, and attr calls that returned plain text or a bare attribute value could still leak a marked secret’s value verbatim — reported by a downstream user, confirmed reproducible on v3.0.6, and fixed by checking the live DOM for the marker before any of those code paths run. A follow-up fix corrected how dialog text renders when an action triggers a native browser dialog mid-flight, which had been showing “unknown” and ”???” placeholders instead of the dialog’s actual text and accept/dismiss instructions. Sole author: Ada Sen (staff). Open but not yet merged as of the snapshot: Ada Sen’s own follow-up scrubbing password/one-time-code fields from capture, and an outside contributor’s (sophieow) addition of a CHROME_WS_HEADLESS environment variable.
