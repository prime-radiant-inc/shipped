prime-radiant-inc/streamlinear

A lightweight Linear MCP server for Claude Code that exposes one tool with action dispatch (search, get, update, comment, create, graphql, help) using ~500 tokens instead of the standard MCP’s ~17,000.

23 commits 23 PRs 🏷 2 releases +40,429 −7,492

Two tagged releases, both with hand-written notes. v1.2.0: labels wired into create/update (names resolve against the workspace label list, clearing the list on update, and an unknown label errors out listing the available options), state and UUID-based assignee support on create/update, a new STREAMLINEAR_POST_ONLY mode that disables search/get/graphql so an agent can create and update issues without ever reading issue content, @mention conversion to Linear profile links when a mention matches exactly one workspace user, a dependency refresh (zod 4, the MCP SDK to 1.32) that cleared every open Dependabot security advisory, and a new end-to-end test suite driving the built MCP server over stdio against a stubbed Linear API. v1.2.1, same day: the CLI’s own create/update gained the same labels/state/assignee options to match the MCP tool, the search assignee filter now accepts UUIDs so “assignee” means the same thing everywhere, a CLI crash when --labels was omitted got fixed, and npm run build on Windows now goes through a Node script calling esbuild’s API instead of a shell pipeline that mis-quoted arguments there. Contributors: Jesse Vincent (staff, obra) and Ada Sen (staff) — one commit, honoring assignee/state/UUID-assignee on create/update — plus dependabot[bot] version bumps.

prime-radiant-inc/evener

554 commits 470 PRs 🏷 v0.3.17 +358,247 −620,293

Tagged release v0.3.17, a bare version tag with GitHub’s auto-generated changelog. The dominant thread this week is a large, two-track internal refactor run under branch tags W1-* and W2-* across the agent, hub, web, native, and appwire-client code: long functions split into named phases, leaf packages extracted (memory pages, host resources, frontmatter editors), and dozens of hand-rolled test-fixture copies replaced by a handful of shared helpers (one connectFakeClient/connectReadyFakeClient pair standing in for duplicated setup across many test files), running in parallel with a “Wave 2” documentation audit closing and ruling on review findings.
