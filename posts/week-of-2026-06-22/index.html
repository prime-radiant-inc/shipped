serf goes public, toil arrives

Week of June 22, 2026 · Jun 22, 2026–Jun 28, 2026 · published Jun 28, 2026

The first week we’re recapping opens with a release we’d been building toward: serf shipped its v0.1.0, its first tagged release. And it’s one of a spread of repos active across prime-radiant-inc and obra, from a brand-new Go workflow orchestrator to a sweeping reshaping of how the eval lab handles model credentials.

The week in numbers

  • 11 repos active (3 featured, 8 also shipped)
  • 568 commits
  • 12 merged PRs
  • +286,576 / −50,088 lines
  • 4 contributors
  • 2 tagged releases

A note on the line count: this was a going-public week, so a large share of the added lines is toil’s one-time initial public release rather than organic day-to-day change. We flag it so the number doesn’t oversell the week.

Featured

prime-radiant-inc/serf

A non-interactive coding agent: give it a prompt and it reads, writes, runs commands, and searches code in a loop until the work is done — native tool-calling across OpenAI, Anthropic, and Google models.

435 commits 3 PRs 🏷 2 releases +145,118 −42,905

serf cut two releases on June 22 — a snapshot prerelease and then its first real tagged release, v0.1.0 — and it was the single busiest repo in either org that week. Three changes landed via merged PRs: a substantial (~58%) speed-up to NewSession by memoizing the per-session git/schema/uname work, an ATIF-v1.7 conformance fix so orphaned tool results stay valid, and a maintainability cleanup pass (shared helpers, table-driven tests, file splits). This is the agent that does the work when nobody’s watching — and it’s now something you can pin a version of.

prime-radiant-inc/toil

A file-defined workflow orchestrator in Go — YAML workflows and runners, disk-persisted state, resume, approvals, and live graph views.

2 commits +111,939 −32

New this week. The initial public release landed the whole project at once, followed by a rewrite of toil help in the “tgwm” style — grouped by audience rather than by flag. toil is the piece that turns a pile of steps into a durable, resumable workflow with approvals and a live view of the graph as it runs.

obra/temp-sp-codex

A temporary test repo for the Superpowers Codex marketplace.

2 commits +91 −10

New this week, and honest about what it is: a throwaway test bed for the Codex marketplace manifest work happening over in superpowers. It added the Codex marketplace manifest and kept the Codex hooks manifest in plugin metadata. It earns a mention because it was created in-window, not because it’s a product.

Also shipped

prime-radiant-inc/superpowers-evals

The Quorum behavioral eval lab — drives real coding-agent CLIs (Claude, Codex, Gemini, Kimi, and more) through a QA agent and grades them on workflow compliance.

91 commits 3 PRs +19,754 −4,381

One of the busiest repos of the week, and almost all of it is a single coherent thread — the “credential axis.” The lab learned to describe every model endpoint in a credentials.yaml with a default_credential, thread that credential through runs, verdicts, and dashboards, and build per-harness provider config (pi, opencode, codex, claude, gemini) from it. Alongside that: a new serf coding-agent harness, per-endpoint concurrency caps keyed on a limiterKey, scenario-local fixtures, and a user-preference-override eval suite.

prime-radiant-inc/llm-proxy

A transparent logging proxy for LLM API traffic — auto-configures clients and records every request and response for debugging, auditing, and analysis.
